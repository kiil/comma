# Reference: publish

Reserved module. Will hold commands that post finished output to external platforms via API — LinkedIn, Drupal, Medium, Mastodon, and similar.

No commands are exported yet. Implementations will be added per platform as they are needed.

For offline file conversion (markdown → PDF/HTML/DOCX/EPUB on disk), see [convert](convert.md).
